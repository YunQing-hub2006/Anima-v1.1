## 代码改动

### 1. `anima/core/lifecycle.py` — 原子性修复（核心）

新增私有 helper（逆加载序、尽力而为、错误聚合）：

```python
async def _unload_everything(self) -> list[BaseException]:
    """按逆加载序尽力卸载全部已加载插件；返回期间的全部异常。"""
    errors: list[BaseException] = []
    for name in reversed(list(self._load_order)):
        try:
            await self.unload(name)   # enabled 的会自动 disable
        except RollbackError as exc:
            errors.extend(exc.errors)  # 展平，不嵌套
        except Exception as exc:
            errors.append(exc)         # 如 disable 钩子抛异常，不阻断其余插件
    return errors
```

三处接入：

- **`load_all`**：把加载 for 循环包进 `try/except BaseException as exc`（BaseException 覆盖 CancelledError 中断场景）。异常时 `rollback_errors = await self._unload_everything()`；有清理失败则 `raise RollbackError(rollback_errors) from exc`（`__cause__` 指向原始异常，errors 为清理失败项——已确认的聚合方案），否则裸 `raise` 原始异常。注意：失败插件自身也已注册（注册先于 load），回滚会连它的部分副作用一起清理——这正是需要的。
- **`enable_all`**：同样模式。回滚为**完整卸载**（`unload` 对 enabled 插件自动 disable），即 enable_all 是全有或全无，失败后可重新 `load_all`。
- **`unload_all`**：改为 `errors = await self._unload_everything()`；`self._load_order.clear()`；`if errors: raise RollbackError(errors)`。单个插件清理失败不再中断其余卸载。

**验证修复方案与报告的差异**（报告的伪代码有 4 处需修正，本计划已吸收）：回滚必须逆加载序而非正序；回滚循环必须逐插件捕获（`unload` 会抛 `RollbackError`，不捕获会中断回滚）；`enable_all` 同样需要回滚；需定义"回滚自身失败"的异常契约（已确认聚合方案）。

### 2. `anima/core/app.py` — start/stop 加固

- **`start`**：`load_all + enable_all` 包进 `try/except BaseException`；except 里先 `bus.clear() / registry.clear() / _effects.clear()` 兜底（覆盖回滚本身出错的残留），再 `raise`。`_started` 仍只在全部成功后置 True（保持"未启动时 stop 是空操作"语义）。失败后可再次 `start`，不再抛重复注册。
- **`stop`**：`unload_all` 包进 `try/finally`，finally 里执行 bus/registry/_effects 清理与 `_started = False`——卸载出错也必然复位，App 可重启。
- 更新两个方法的 docstring 说明错误语义。

### 3. `anima/core/bus.py` — 移除死排序

- `_wild_matches` 删除 `matched.sort(key=_is_coroutine_fn)`（行为不可观察，纯死代码）。
- 删除因此孤立的 `_is_coroutine_fn`（本改动产生的孤儿，按规范清除）。
- 模块 docstring 补一行真实顺序契约：**精确订阅 handler 先于通配 handler；各自内部按注册顺序执行**。

### 4. `anima/core/context.py` — 注解修正

- 第 8 行改为 `from anima.core.effects import CleanupFn, EffectTracker`（已验证 import 链无环：context → effects → exceptions）。
- 第 28 行改为 `effects: EffectTracker`（去引号）。

### 5. 版本号

`anima/core/__init__.py`：`__version__ = "1.1.0"` → `"1.1.1"`（缺陷修复版，公共签名不变）。
